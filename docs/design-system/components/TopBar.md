# TopBar

Barre du haut de 38px (`size-topbar`) : fenêtre principale (bar.html) et en-tête des fenêtres Réglages et Easel (`#top`).

- Fond : lueur `accent-glow` depuis le coin haut gauche (700 × 500px) sur `tint-top` ; Réglages/Easel reprennent la même recette.
- macOS : retrait gauche `size-traffic-lights` (84px). Windows : boutons de fenêtre 46px à droite.
- Omnibox : hauteur `size-omnibox`, `radius-card-sm`, `fill-hover-strong` + `border-default`, centrée ; survol `fill-pressed`, `border-hover`, `shadow-omni-hover`.
- Puce « Not secure » : voir Badge. Barre de chargement : `size-progress`, dégradé `accent` → `loader-gold`, `shadow-progress`, scintillement 1.2s.
- Réglages/Easel : marque = logo 18px + titre 13px/600.
