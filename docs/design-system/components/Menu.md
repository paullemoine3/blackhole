# Menu

Menu contextuel natif du shell, rendu dans la vue de la palette (palette.html `#menu`), ancré au clic et contenu dans la fenêtre.

- Panneau : 190–280px, padding 6px, `radius-panel`, `surface-menu`, bordure `border-field`, `shadow-menu` ; entrée `menuin` (scale .88 → 1, .22s, `ease-pop`) depuis le coin du clic.
- Item : padding 6px 10px, `radius-control`, 13px, icône 15px dans une case 18 × 16 ; survol `accent-selection` + blanc.
- Danger : texte `danger-text`, survol `danger-fill` ; armé : `danger-fill` permanent.
- En-tête de groupe : 11px capitales .08em à `opacity-section` ; séparateur 1px `border-default`.
- Pastille de couleur : 16px rond, liseré blanc .25.
