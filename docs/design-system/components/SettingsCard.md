# SettingsCard

Carte de section, commune à Réglages et à l’accueil : `fill-card`, bordure `border-card`, `radius-panel` (14px), 18px entre cartes.

- **Liste** (Réglages, `.bh-scard`) : padding 6px ; les rangées `.opt` / `.row` font 10px de padding, `radius-control`, survol `fill-hover`, puis `.actions` (écart 8px, padding 10px).
- **Contenu** (accueil, `.bh-hcard`) : padding 18px.
- Titre : `section-label` (11px capitales, .08em, `opacity-section`).
- Statut d’appareil : point 8px, en ligne `success`.
