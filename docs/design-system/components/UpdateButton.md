# UpdateButton

Bouton pleine largeur en bas de la barre latérale, présent seulement quand une version plus récente existe (index.html `.update`).

- Fond : dégradé 135° de `accent` vers `fill-glint` ; contour `shadow-ring`.
- Survol : `shadow-update-hover` (lueur de l’espace), l’icône rebondit (`up-bounce` .7s) et un reflet traverse (`up-shine` .9s).
- Occupé : opacité .85, icône qui tourne. Erreur : dégradé depuis `danger-solid`.
