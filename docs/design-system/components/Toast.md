# Toast

Message transitoire, un seul composant partout : `surface-toast`, bordure `border-strong`, `radius-card-sm`, padding 8px 12px, 12px. Il peut porter des actions (bouton sm : primaire `accent`, secondaire `fill-control-strong`).

- **Ancré** (barre latérale) : en bas, 54px au-dessus du pied, largeur de la barre ; entre avec `ease-pop` (−10px, scale .97) en `duration-base`.
- **Centré** `.center` (Easel) : centré à 20px du bas, largeur du contenu ; même entrée.
- **Aide du mode aperçu** (peek.html) : pastille `radius-pill` sur `surface-panel`, bordure `border-field`, sur le voile `scrim`.
