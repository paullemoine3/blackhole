# Badge

Petits marqueurs d’état et d’information.

- Compteur d’extension (bar.html `.badge`) : 14px de haut, `accent`, 9px/700, `radius` 7px.
- Privé (`.priv`) : pastille `radius-pill`, `fill-pressed`, 12px.
- Non sécurisé (`#insecure`) : 20px, `radius-chip`, `danger-text-soft` sur `insecure-fill`, bordure `insecure-border`.
- Compteur de bloqueurs (`.bl .n`) : 12px/600, `fill-control-strong`, `radius-card-sm`.
- Touches (`kbd`, un seul style partout : Réglages, palette, aperçu) : mono 12px, padding 1px 6px, `fill-control-strong`, `radius-chip`, sans bordure ; notation via `bhKeys()` (⌘⇧E sur macOS, Ctrl+Shift+E ailleurs).
- Code : mono 12px, `fill-raised`, `radius-chip`.
- « new » de la Bibliothèque : `accent`, padding 2px 8px.
- Statut : point 8px, `success` en ligne.
