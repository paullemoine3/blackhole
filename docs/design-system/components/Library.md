# Library

Bibliothèque (library.html) : historique, notes, téléchargements, collections. Elle reprend désormais les tokens du shell.

- Fond `bg-page`, texte `text-primary`, secondaire `text-secondary`, tuiles et colonnes `fill-raised`, accent `accent`.
- Navigation : SettingsNav (210px, actif `accent-wash`).
- Titre `title-settings`, police `font-sans`.
- Rangées `radius-control`, padding 8px 12px, survol `fill-card`. Tuiles et cartes soulevées : `shadow-tile-lift`.
- Notes : seule surface claire de l’app, gardée exprès (`lib-note-bg`, `lib-note-fg`, `lib-note-dim`).
- Les animations obéissent au réglage `body.noanim` et à `prefers-reduced-motion`.
