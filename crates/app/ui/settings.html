Protection

Without a master password, the key is kept in the system keychain (Windows Credential Manager, macOS Keychain) and the passwords open with your session. With one, they stay locked until you type it, and lock again after the delay above. A forgotten master password cannot be recovered: the passwords are lost.

Safari web extensions shipped by apps installed on this Mac (for example Bitwarden). They run on the same native host, with their toolbar button and popup. Features that rely on the app itself (Touch ID unlock, native messaging) are not available.

Paired devices

Pair a device

Type this code in BlackHole on the other device (Settings › Devices). It works for 5 minutes, only once.

How it works

Both devices must be on the same local network; there is no server and no account. Only the address of the tab travels (and where a YouTube or Twitch video was), encrypted with a key known to the two paired devices: no cookies, no session, so you may have to sign in again on the other device. Nothing listens on the network until a device is paired: the first time, Windows or macOS asks to allow BlackHole on the local network.

Tab sync keeps quick access, open tabs and spaces (name and color) the same on both devices; private windows, folders and history stay on each device. Ask proposes to merge when the device comes back on the network, Always merges on its own, Off never syncs. A tab closed on one device closes on the other.

Passwords: export them from the other browser's password manager (Chrome, Edge, Brave, Firefox, Waterfox, Safari, Bitwarden…) to a CSV file. They are added to Settings › Passwords (encrypted on this device). Delete the CSV afterwards, it is not encrypted.
