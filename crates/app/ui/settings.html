Extensions

Real WebExtensions run on the system's native extension host, plus simple content-script extensions.

Catalog

Each entry is downloaded over HTTPS from its official release and checked against a pinned SHA-256 before it is installed.

Found in your apps

Safari web extensions shipped by apps installed on this Mac (for example Bitwarden). They run on the same native host, with their toolbar button and popup. Features that rely on the app itself (Touch ID unlock, native messaging) are not available.

Installed

Drop an extension folder (with its manifest.json) in , then press Reload. Turning an extension off removes its styles at once; reload the page to stop its scripts.

Import

Bring your bookmarks and passwords from another browser. Nothing leaves this machine.

Detected browsers

Bookmarks are read straight from the browser's profile (read-only). Imported bookmarks appear in the command bar search.

From a file

Passwords: export them from the other browser's password manager (Chrome, Edge, Brave, Firefox, Waterfox, Safari, Bitwarden…) to a CSV file. They are stored in a vault encrypted with a key kept in the system keychain. Delete the CSV afterwards, it is not encrypted.
